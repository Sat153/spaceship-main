## CREATIVE LAB — SOP SUMMARY

### Event Card Must Include
- Event Name & Date
- Event Type (Press Event / Field Visit / Festival / Announcement)
- Raw Content Upload (Photos & Videos)
- Assigned: Lead Designer + Lead Video Editor

### Responsibilities
**Images:** Select best photos based on clarity, expression, storytelling value
**Video:** Clean transitions, proper pacing, clear narrative flow
**Graphics:** Consistent visual identity, minimal yet impactful design

### CRM Workflow Stages
1. Raw Content Uploaded
2. In Editing
3. Internal Review (Creative Lab QA)
4. Ready for Approval

### Internal QA Checklist (before marking Ready)
- [ ] Correct number of images per platform
- [ ] High visual quality & consistency
- [ ] Proper image sequencing (especially Instagram)
- [ ] Video quality, audio clarity, clean editing
- [ ] No duplication or irrelevant content

### File Naming Convention
```
Format:  Date_Event_Platform_Type_Version
Example: 20Apr_KisanEvent_Instagram_ImageSet_V1
```

### Cloud Folder Structure
- `/Raw Content`
- `/Edited Content`
- `/Final Output`

## PR & SOCIAL MEDIA — SOP SUMMARY

### Event Card Must Include
- Event Name & Date
- Event Type
- Linked Creative Assets (from Creative Lab)
- Assigned PR Owner

### Caption Rules by Platform
| Platform | Style | Images |
|---|---|---|
| Twitter (X) | Concise, sharp, politically aligned | Exactly 4 images |
| Instagram | Descriptive, visual storytelling | 10 preferred, min 6 mandatory |
| Facebook | Detailed, structured for readability | Same set as Instagram |

### CRM Workflow Stages
1. Caption Drafting
2. Internal Review (PR QA)
3. Ready for Approval
4. Sent for Approval
5. Approved
6. Posted
7. Verified

### Internal QA Checklist (mandatory before approval)
- [ ] Grammar & language accuracy (Hindi/English)
- [ ] Political correctness & tone
- [ ] Proper tagging (leaders, ministries, departments)
- [ ] Caption–platform alignment
- [ ] Final image/video set is correct

### Post-Publishing Verification
- Caption accuracy ✓
- Image/video correctness ✓
- Tags & formatting ✓
- Update CRM status to **Verified**

### Special Rule
> All relevant posts from **PM Narendra Modi** must be promptly retweeted, timed for maximum visibility.
